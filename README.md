# footballhub

## Über das Projekt
**footballhub** ist ein PHP-basiertes Webprojekt mit Fußballbezug, das im Rahmen meiner Umschulung zum Fachinformatiker für Systemintegration entstanden ist.

## Ziel des Projekts
Der Schwerpunkt des Projekts lag auf der praktischen Umsetzung von:
- Login-Funktionalität
- unterschiedlichen Benutzerrollen
- rollenbasierten Zugriffsrechten auf Inhalte und Funktionen

Das Projekt diente primär Lern- und Demonstrationszwecken und war nicht als vollständig fertige Anwendung für den allgemeinen öffentlichen Einsatz konzipiert.

## Technologien
- PHP
- CSS
- MariaDB
- DBeaver
- FileZilla

## Datenbank
Die Datenbank wurde mit **MariaDB** umgesetzt und während der Entwicklung mit **DBeaver** verwaltet.

## Deployment
Die Bereitstellung auf dem Server erfolgte per **FileZilla**.

## Hinweis
Dieses Repository dokumentiert ein Ausbildungsprojekt. Es zeigt den Entwicklungsstand und die umgesetzten Konzepte, erhebt jedoch keinen Anspruch auf eine vollständig produktionsreife Anwendung. Dies wäre bei der relativ kurzen Projektphase auch ein bisschen zu hoch gegriffen.
